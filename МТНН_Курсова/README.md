# README

## Проект MTHH_Kypcoва


### Структура файлів і папок:

- **`data/`**  
  Папка з даними, включає файли гіперспектральних зображень 

- **`Image_pred/`**  
  Папка для збереження результатів прогнозування зображень(в full_image_prediction.py) .

- **`ASSRF_TOD.py`**  
  Основний скрипт для тренування моделі ASSRF із TOD+COD. Тут знаходится модифікований алгоритм, який використовує TOD+COD для активного навчання та також реалізує псевдомаркування.

- **`assrf_tod_model.pkl`**  
  Збережена модель ASSRF, навчена на даних.

- **`full_image_prediction.py`**  
  Скрипт для виконання прогнозування повного зображення із використанням навченої моделі, для демонстрації роботи.

- **`RF.py`**  
  Скрипт із реалізацією стандартного Random Forest для порівняння або базового класифікатора( має 2 типи лісу, з 140 початковими пікселями в тренувальному сеті(по 10 пікселів на клас) і другий з 640px(140+10 пікселів кожну епоху(50 епох)).
Для порівняння стандартного Random FOrest з однаковою кількістю початкових данних. RF з 640 пікселів для навчання дає точність +-87%, в той же час модифікований алгоритм має точність +-92.5% при отриманні такої самої кількості маркованих пікселів(640)
